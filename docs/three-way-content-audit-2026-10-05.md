# 교재 5권 · 사용자 요약 PDF · SQL 노트 내용 대조

검토일: 2026-10-05. 사용자가 확인한 범위는 **1-1, 1-2, 2-1, 2-2, 2-3 교재 전체**다. 교재의 학습 내용을 기준으로 사용자 요약 PDF와 현재 앱에 있는지를 각각 비교했다.

**두 자료 모두 교재의 모든 세부 내용을 담고 있지는 않으며, 빠진 위치가 서로 다르다.** 요약본에 없는 반정규화·관계대수는 앱에 있다. 반대로 요약본과 교재에 있는 SQL Server TOP·일부 함수·정규식 표기는 앱에 없다. 큰 단원 이름의 존재만으로 세부 내용까지 있다고 판정하지 않았다.

교재 합계는 **324쪽**이다. 사용자 요약본은 사용자가 자신의 정리본이라고 지정한 자료로 취급했다. 과거의 '요약본 → 앱' 비교를 재활용해 끝내지 않고, 이번에 처음 확인한 교재의 본문·예제·문제 해설에서 학습 항목을 추출해 양쪽을 다시 대조했다. 현재 APK 내부의 세 콘텐츠 JSON이 작업 폴더 자산과 같은지도 확인했다.

요약 PDF는 텍스트 추출에 가려진 문장이 섞이는 부분이 있어 관련 페이지의 실제 그림을 확인했다. 교재의 도표·ERD·결과표 및 판단이 필요한 부분도 실제 렌더링을 확인했다. 모든 페이지를 읽는 것과 모든 문항의 정답을 독립적으로 검증하는 작업은 구분했다.

## 판정 읽는 방법

- **있음:** 동일한 학습 개념·규칙·판단 기준을 설명한다. 예제의 이름이나 문장이 같을 필요는 없다.
- **부분:** 주제는 있지만 교재의 특정 조건·변형·반례 설명이 부족하거나, 앱의 문제 해설에만 있어 본문 학습이 부족하다.
- **없음:** 해당 학습 내용의 설명을 찾지 못했다. 일반적인 상위 개념이나 무관한 문장의 단어 일치는 포함 증거로 쓰지 않았다.
- **정확성 주의:** 설명의 충돌, 조건 생략, 도표·정답·해설의 불일치를 별도로 기록했다. `있음`은 그 문장이 정확하다고 인증한 뜻이 아니다.

내용 추가 여부를 결정하기 위한 **AI 비교 검토**다. 교재의 내용이 전부 현행 시험 필수 범위라는 주장이나 출제 빈도·합격 가능성의 판정은 아니다. 이번 작업에서 앱 코드·학습 콘텐츠·학습 기록·원본 PDF·APK는 변경하지 않았다.

## 단순 누락과 구분한 설명 충돌

예를 들어 교재 2-3의 4쪽은 기반 테이블 삭제 후 뷰가 무효 상태로 남는다고 설명하지만, 사용자 요약 36쪽은 뷰도 삭제된다고 설명한다. Oracle에서는 종속 뷰의 정의가 남고 무효화되는 것이 맞다. 앱의 관련 설명을 요약본 문장에 맞추어 바꾸면 안 된다. [Oracle DROP TABLE](https://docs.oracle.com/en/database/oracle/oracle-database/19/sqlrf/DROP-TABLE.html).

또한 식별/비식별 관계와 필수/선택 참여, 부모 삭제 시 자동 전파는 구별해야 한다. 부모 키가 자식 PK에 들어가는지 여부만으로 SQL의 자동 연쇄 삭제를 결정하지 않는다. Oracle의 참조 동작은 제약과 `ON DELETE` 옵션에 따른다. [Oracle 제약조건](https://docs.oracle.com/en/database/oracle/oracle-database/19/sqlrf/constraint.html).

교재 자체에서도 발견한 정답 번호와 해설 숫자의 충돌, 요약본의 과도한 일반화는 상세 표의 '주의'에 따로 적었다. 이를 누락 개수로 세거나, 발견된 항목 외에는 모두 정확하다고 판단하지 않았다.
