# 0.10.0 학습 진도 동선 개선

이번 변경은 여러 곳에 나뉘어 있던 ‘다음 공부’를 63강 학습 진도 중심으로 정리한다. 기존 Canva 기반 Compose 테마, 학습 내용, 문제, 기록 저장 형식은 유지한다.

## 사용 흐름

1. 홈의 **내 학습 진도 → 강의 공부 이어서**로 읽던 강의를 연다. 처음 사용하는 경우 **1강부터 공부하기**를 누른다.
2. 강의 상단의 **1 설명 → 2 개념 → 3 예제 → 4 확인**에서 현재 위치를 본다. 하단 고정 버튼으로 다음 단계에 간다.
3. 개념에서 **읽기 완료 · 예제 보기**를 누르면 자료 읽음을 저장한다. 예제는 각 결과를 확인하고, 확인 문제는 ‘이해’ 또는 ‘다시 보기’를 표시한다.
4. 모든 단계를 확인하면 하단 버튼으로 다음 강의에 간다. 누락이 있으면 읽기·예제 단계로 돌아가는 버튼을 제공한다.
5. 다른 강의는 **진도** 메뉴에서 고른다. 마지막 강의를 모두 확인하면 전체 진도로 돌아간다.

강의 화면의 **추가 해설·문제·학습 도구** 안에는 상세 해설, 유형별 문제, 수동 읽음 표시·취소, 연결 개념, 이전·다음 강의 자유 이동, 전체 목차가 있다. 홈의 **학습 도구 더보기** 안에는 개념 찾기·학습 계획·핵심 개념 진도·학습 기록이 있다. 기존 기능을 삭제하지 않고 주 학습 동선에서 분리했다.

‘읽은 강의’는 자료 읽음 표시 수다. 단계 완료는 예제 결과 확인·자기 평가를 포함하는 학습 기록이며, 자동 채점 점수나 숙달 판정이 아니다. ‘다시 보기’를 선택한 확인 문제는 다음 강의로 이동해도 복습 대상으로 남는다. 자유 이동은 완료로 처리하지 않는다.

진행 중 문제는 **풀던 문제 이어서**로 재개한다. 실전 시험은 홈에서 가장 먼저 표시하고 기존 제한 시간·도움 전환 확인 절차를 유지한다.

## 변경 코드와 보존

- `LearningScreens.kt`: 홈의 주 동선과 접을 수 있는 학습 도구.
- `MainActivity.kt`: 하단 **진도** 메뉴를 63강 목차에 직접 연결. 개념 노트 경로는 유지.
- `CourseScreens.kt`: 현재 강의·단계 표시와 하단 고정 다음 버튼. 저장 성공 후 화면 단계를 변경.
- `CourseJourney.kt`: 기존 기록에서만 다음 강의·확인 상태를 계산. 별도 저장 필드나 마이그레이션 없음.
- `CourseJourneyTest.kt`, `LearningFlowUiTest.kt` 및 기존 UI 검사: 순서·복귀·도구 접근 회귀 검사.

문제·보기·SQL·정답·예시·강의 ID·자기점검 ID는 변경하지 않았다. 콘텐츠·앱 자산·Room schema의 기존 **535파일**은 작업 전 백업 해시와 바이트 단위로 동일하다. 채점 문항1,600개, 63강, 95예제, 강의 자기점검189개를 유지한다.

Room schema1·백업 schema3을 유지한다. 기존 제출·진행 중 시험·진도·오답·필기·설정은 그대로 사용한다. 읽던 화면·스크롤을 강제로 첫 미완료 단계로 되돌리지 않는다.

## 설치와 되돌리기

`dist/SQL-note-0.10.0-release.apk`를 기존 앱 위에 같은 개발 서명으로 설치한다. ADB는 `adb -s <기기ID> install -r dist/SQL-note-0.10.0-release.apk`를 사용한다. 앱 삭제나 데이터 초기화는 필요하지 않다.

화면 변경을 되돌리려면 작업 전 소스 백업을 별도 디렉터리에 풀고 이전 소스로 **versionCode를 현재 설치보다 높여** 같은 서명으로 다시 빌드한다. 현재 콘텐츠와 기록 형식은 변경되지 않았다. 기기 기록은 먼저 **설정 → 전체 기록 내보내기**로 보관한다. 낮은 versionCode의 예전 APK를 설치하려고 앱을 제거하지 않는다. 기록 교체가 필요한 경우 기존 백업 검사·미리보기·복구 지점 절차를 사용한다.
