## 기존 기록 보존

기존 0.4.1 릴리스는 non-debuggable이므로 `run-as`를 통한 내부 DB 복사는 불가능했다. 대신 설치 전에 앱의 **전체 기록 내보내기**로 로컬 백업을 확보하고, 앱의 백업 검사 화면에서 정상 미리보기까지 확인한 뒤 **기존 기록 유지**로 취소했다. 복원은 실행하지 않았다.

원본 JSON은 `private-*-backup.json`으로 로컬 evidence 폴더에만 두며 배포 소스 ZIP에서 제외한다. 비교 결과에는 개인 메모·필기·답안 본문을 넣지 않았다.

- 최종 디버그/릴리스 업데이트 직전과 릴리스 화면 확인 후의 payload SHA-256은 모두 `a4d7939d436e527c4817c2c5f50a1f882e82faa4c0dfa2306125471a3a4bd4bf`이다. **payload 완전 일치**, 차이 0곳이다. 증거: `release-update-state-comparison.json`.
- 최초 0.4.1 백업과 최종 백업의 제출 55개, 세션 5개, 필기 2개, 강의 진도 5개는 유지됐다. 제출·별표·필기·메모·복습·노출·설정·강의 진도와 마지막 위치 등 비교한 보호 필드 13개가 모두 동일하다.
- 최초 QA 중 기존 이어보기 문제 화면을 확인한 결과 revision 582→607, 해당 세션/첫 문항 시간 10,000→125,000ms, 첫 문항 scroll 0→794가 변했다. 답안 제출이나 기록 교체는 하지 않았다. 이 차이를 숨기거나 되돌리지 않았다. 증거: `final-vs-original-state-comparison.json`.
- 작업 종료 시 화면을 이번 작업 시작 당시 확인한 720×1600px / 320dpi / 글씨 1.0 / 야간 모드 no로 돌리고 오늘 화면에 두었다. 오래된 공용 baseline 파일 대신 이번 `backup-start-environment.json`의 실제 값을 적용했다.
