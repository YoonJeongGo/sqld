사용자 요청은 별도 계획표 제작이 아니라 현재 Android 앱 화면의 시각 디자인 변경이다. 현재 Compose 구현을 유지하고 화면 배치·색·글꼴·컴포넌트를 변경한다. 콘텐츠·문항·계획·진도 저장 구조를 바꾸지 않는다.

- Canva 디자인의 텍스트·구성을 커넥터로 읽고 첫 페이지 실제 미리보기를 브라우저로 확인했다. 생성 시안의 예시 진도/합격률/일부 오타는 앱 데이터나 학습 내용으로 사용하지 않는다.

- Canva 로그인이나 네트워크를 앱 실행 조건으로 추가하지 않는다. 사용자 PDF, 답안, 메모, 원시 학습 기록을 Canva로 전송하지 않았다.
- 이전 `DAHXIgecBnA`는 별도 계획표 초안이다. 이번 앱 디자인 작업과 구별하며 보류 상태를 바꾸지 않았다.

변경 전 코드/콘텐츠 233개 파일을 `backups/ui-redesign-before-20261005-212229.zip`에 보존했다. 이전 0.5.0 APK와 소스 ZIP도 유지한다. 기존 학습 기록은 전용 에뮬레이터에서 앱의 내보내기 기능으로 별도 백업했으며 원시 백업은 배포 ZIP에서 제외한다.
