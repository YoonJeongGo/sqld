# 0.3.0 — 63강 자료와 별도 학습 진도

작업일: 2026-09-28. 사용자 요청: 보내 준 자료를 현재 앱에 넣고 강의별 진도를 구분한다.

## 학습 동선

- 오늘 → 63강 학습 진도 → 이어보기 또는 전체 진도.
- 노트 → 강의 순서 / 개념별. 하단 탭은 기존 5개를 유지한다.
- 강의 → 핵심 정리 / 개념 / 예제 / 자기 점검. 단원 5개, 강의 63개를 순서대로 제공한다.
- 강의와 기존 개념 노트를 서로 연결한다. 강의에서 연습을 시작할 때 모의고사 문항은 노출 이력과 무관하게 제외한다.
- 강의 읽음, 예제 결과 확인, 자기점검 이해/다시 보기를 분리한다. 강의 시간은 원 영상 안내 시간이며 앱 수강시간 또는 완료 인증이 아니다.
- 강의·화면·스크롤·풀이 단계·서술형 답안·자기평가를 저장한다. 시험 정답률에 자기평가를 합산하지 않는다.

## 콘텐츠

63강, 개념 490개, 예제 95개, 자기점검 189개, 표 223개, SQL 70개, SVG 63개. 기존 41개 노트와 661개 창작 문항은 별도 유지했다. 원본 자료는 수정하지 않았고, 도해·GROUPING_ID의 모호한 설명·조사 오류는 정규화 팩에서 수정했다.

수정 내역과 출처 확인의 실제 범위는 [콘텐츠 검토](course-content-review.md)에 있다. SQLite 원문 실행 50개와 동등식 10개는 현재 실행 결과가 예상표와 일치한다. 나머지 35개, Oracle/SQL Server 실제 실행, 사람 전문가 검수는 완료한 것으로 표시하지 않는다.

## 기록 보존과 수정한 오류

- Room 스키마·테이블은 1을 유지한다. JSON 학습 상태 및 백업은 v2이며 v1 데이터를 이전한다.
- 새 백업을 이전 앱이 읽고 강의 진도를 버리지 않도록 백업 envelope도 v2로 올렸다.
- v1 백업 복원도 전체 교체다. v1에는 강의 진도가 없으므로 현재 강의 진도가 비워지며, 교체 전 진도는 복구 지점에 보관된다. 이를 병합 복원으로 표시하지 않는다.
- 기존 문제·보기·노트·블록 ID, 제출·문항 스냅샷·ExamSpec은 유지한다.
- 복원 전 검사·수량 미리보기·복구 지점·원자적 교체를 유지한다.
- 복원이 끝난 뒤 이전 화면의 비동기 스크롤 저장이 복원 결과를 덮을 수 있던 경합을 저장소 세대 검사로 막았다.
- 복원 중 확인 버튼 중복 클릭과 취소를 차단해 복구 지점이 다시 덮이거나 취소 안내와 실제 동작이 어긋나지 않게 했다.
- 실전 모의고사 중 강의 목록 또는 본문을 열 때 연습 전환 확인을 적용한다. 기존 답안은 보존한다.
- 개념도 WebView가 영역 밖에 그려져 닫기 버튼을 가리던 문제를 경계 클리핑으로 수정하고, 처음에는 전체 도해가 보이도록 화면 폭에 맞췄다. 확대해서 세부 내용을 읽을 수 있다.
- 작은 화면에서 강의 목록의 설명이 본문을 밀어내지 않도록 진도 집계 안내를 접고, 실전 전환 버튼 문구를 줄였다.

Android 검사는 전용 `SQLNote_QA` API34 에뮬레이터에서 실행했다. Room 통합 테스트는 사용자 DB와 격리해 강의 저장·재열기, v1 백업 이전, 원자적 복원·실패 rollback·복구 지점, 복원 직후 오래된 화면 저장 차단을 검사한다. UI 검사는 답안·평가·예제·읽음의 지속성, 실전 전환/취소와 기존 답안 보존, 연결 연습의 모의고사 제외를 확인한다.

초기 실패는 모의고사 연결이 없는 강의를 고른 테스트 자료, 비동기 저장 대기 부족, 큰 글씨에서 중첩 버튼까지 스크롤하지 못한 테스트 동작을 수정한 뒤 다시 실행했다. 최종 두 Android 로그가 통과 증거이며 초기 실패 로그도 보존했다. 소스 코드의 존재만으로 기기 검증을 완료했다고 해석하지 않는다.

최종 **release APK**를 제거 없이 업데이트 설치하고 강의 목록, 입력한 자기점검 답안의 유지, 개념도의 전체 표시·닫기 버튼을 직접 조작·촬영했다. 360×800dp 일반 화면, 320×640dp·200%·다크, 1280×800dp 가로 태블릿 창을 확인했다. 대표 캡처는 `evidence/course-release-final-{list,resume,diagram,font200,tablet}.png`와 각 환경 JSON이다. 태블릿 창은 에뮬레이션이며 실물 Galaxy Tab 증거가 아니다.

현재 릴리스 프로세스 logcat에 FATAL EXCEPTION/Fatal signal은 없었고, APK에 인터넷 권한은 없다. 최종 에뮬레이터 크기·밀도·글씨·야간 모드는 작업 전 값으로 복구했다. 전체 결과와 APK SHA256은 `evidence/course-qa-summary.json`, 배포 파일의 해시는 `dist/manifest.json`에 있다.

## 범위 한계

사용자가 제공한 창작 학습자료의 통합이다. 흥달쌤 강의 전문·영상, 실제 기출문제, 공식 출제 빈도, 합격 효과를 확인한 것으로 표시하지 않는다. 사람 전문가 검수, Oracle/SQL Server 엔진, Galaxy S24+/Tab 실물, TalkBack 실기기 사용은 별도다. 공개 배포·계정·결제·네트워크 권한은 추가하지 않았다.
